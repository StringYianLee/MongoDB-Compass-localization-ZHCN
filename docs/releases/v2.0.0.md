## MongoDB Compass 简体中文本地化工具 v2.0.0

**发布日期**：2026-10-25  
**适用环境**：Windows 10 / 11（x64）· MongoDB Compass 1.53.0 / 1.53.1  
**安装包**：`CompassZhCn-2.0.0-x64.msi`（88,043,520 字节）

---

### 版本号

`v2.0.0`（安装包内部版本 2.0.0，ProductCode 已更新；UpgradeCode 沿用，可直接覆盖升级 1.x）

### 主要变更

- **界面框架重构**：图形界面由 Tkinter 迁移到 **Flet（Flutter）1.0**，采用 Material 3 控件、圆角卡片与原生对话框，明暗主题与高 DPI 显示更自然。
- **新增 Web 版**：与桌面端共用同一套界面与核心逻辑，浏览器访问 `http://127.0.0.1:8560`，支持响应式布局。
- **打包体系升级**：新增 Flet 桌面绿色版、Web 独立服务器 exe；MSI 升级至 2.0.0，内置 Flet/Flutter 运行时，目标机无需安装 Python。
- **主页布局重构**：状态卡、安装位置、操作区、状态徽标、日志面板与页脚统一排布，窗口缩放自动适配。

### 新增功能

- **Web 端**：同一套汉化/还原/备份/版本信息功能，浏览器内操作；宽屏四卡一行，窄屏自动换行，手机宽度单列堆叠。
- **中文字体支持**：Web 渲染器（CanvasKit）内置中文字体注册，浏览器端中文显示与桌面一致。
- **状态徽标 + 加载环**：执行任务时显示 `ProgressRing` 与「执行中」徽标，替代旧的不确定进度条。
- **响应式卡片**：窗口变窄时四张状态卡自动换行，不再出现挤压或截断。
- **外链按钮**：下载 Compass、打开官方下载页等改为浏览器原生外链，Web/桌面行为一致。

### 修复的问题

- 修复暗色模式下「MongoDB 版本 → 下载安装 → 选择版本」下拉菜单文字与背景对比度不足的问题。
- 修复主页页脚下方出现大面积灰色矩形的问题（隐藏进度条轨道与内容列空白区误绘制）。
- 修复日志面板在部分窗口尺寸下整体不渲染、只显示灰块的问题。
- 修复 Flet 1.0 下 `Column` 不支持 `padding`/`bgcolor` 导致的启动报错。
- 修复 Web 端中文显示为「豆腐块」的问题。
- 修复宽屏下第四张状态卡被挤到第二行的问题。

### 升级注意事项

1. **安装前请完全退出 MongoDB Compass**，避免文件占用导致写入失败。
2. 支持从 1.x 直接覆盖安装；若安装程序提示已存在旧版本，可先在「应用和功能」中卸载旧版再安装。
3. 升级后语言包需要重新注入：打开工具点击一次「一键汉化」，重启 Compass 即可生效。
4. 历史备份保留在 `%LOCALAPPDATA%\CompassZhCn\backup`，升级不会删除；界面主题与窗口尺寸配置（`ui.json`）兼容。
5. Web 版默认仅监听 `127.0.0.1`，汉化操作作用于运行服务的本机；请勿直接暴露到公网。
6. 单文件 exe 由 PyInstaller 打包，部分杀毒软件可能误报，请以本页 SHA256 校验为准。
7. 若 Compass 大版本升级后出现部分英文回退，属于新文案未覆盖，欢迎提交 Issue/PR 补充词条。
